# Errata 用户指南

> 面向第一次使用 Errata 的人。App 内同一份内容在 **设置 → 帮助 → 使用手册**；
> 首次启动会自动显示 5 页快速引导，可跳过，之后也能在手册里点「重看 5 页快速引导」。

---

## 1. Errata 是什么

Errata（/ɪˈrɑːtə/，出版术语「勘误表」）是一个**离线优先**的 Android 错题本：

拍照 → 透视矫正 → 本地 OCR 或视觉模型切题 → 框选入库 → 多标签分类 → AI 讲解 / 整理 / 出同类题 → 按标签生成可打印练习卷。

几条前提：

- 题目、图片、对话都只保存在这台手机，没有账号系统。
- 不配 API Key 也能完成拍照、识别、题库、标签、搜索、统计和「整理错题」练习卷。
- AI 是可选能力；只有你主动使用 AI 时，当前内容才会发给你配置的服务商。
- 系统云备份已关闭（`allowBackup=false`），**卸载或清除数据前请先导出 ZIP**。

---

## 2. 第一次打开

1. 开屏动画结束后，会出现 **5 页快速引导**：欢迎、扫描入库、标签分类、AI 可选、数据与隐私。
2. 可以点右上角「跳过」，也可以看完点「开始使用」；系统返回键等同于跳过。
3. 在最后一页可以点「打开完整使用手册」直接翻到本文对应的页面。
4. 第一次点「立即扫描」时系统会申请相机权限。拒绝也没关系：题库右上角「+」可以手动建题。
5. 引导只显示一次。之后从 **设置 → 帮助 → 使用手册** 随时打开；手册里还能重看快速引导。

> 从旧版本升级上来的用户也会看到一次引导（本地没有「已看过」标记），直接跳过即可。

---

## 3. 三步上手

### 3.1 扫描入库

1. 打开「扫描」Tab，点「立即扫描」。
2. 把整页错题铺平、光线打匀，四个角都留在画面里，然后点按拍摄。
3. 在四角调整页把四个手柄拖到纸的四个角上，确认后开始识别。
4. 识别完成后，点按要入库的题框；可以「全选」「反选」「重拍」。
5. 需要的话现场新建标签并勾选，然后点「存入题库（N 题）」。

说明：

- 配了视觉模型时，会先让 AI 直接框出题目；失败会自动退回本地 ML Kit 中文 OCR，页面上会标明本次来源。
- 本地 OCR、切题、透视矫正都在手机上完成，图片不会上传。
- 识别结果不理想时，重拍通常比手改更快：纸要平、光要匀、四角要完整。

### 3.2 整理与分类

- 在「题库」点开题目，可以改题干、补标签、查看答案与解析。
- 答案与解析可以用「AI 整理」生成，生成结果会先给你预览和编辑，再保存。
- 标签就是分类，也是收藏夹：一题可打多个标签，标签可改名、改色、调排序。
- 「收藏夹」只是勾选了「作为收藏夹」的标签，不单独存一份数据。
- 删除标签只解除分类，**不会删除题目**。

### 3.3 用起来

- 「AI 对话」里问思路、讲题，也可以从题库带题进来。
- 「生成」里按标签出一张练习卷，预览后打印或另存为 PDF。
- 设置里可以导出 ZIP 备份、看学习统计、切换界面风格。

## 4. 五个入口

| 入口 | 用途 |
| --- | --- |
| **题库** | 浏览、搜索、按标签筛选；右上角新建纯文字题目或批量选择、删除。 |
| **扫描** | 拍照 → 透视矫正 → 识别切题 → 框选入库。 |
| **AI 对话** | 会话列表；流式回复、思考过程、公式、附图提问、从题库带题。 |
| **生成** | 按标签抽题，整理错题或让 AI 出同类题；预览后打印 / PDF。 |
| **设置** | API 配置、标签与收藏夹、学习统计、外观、数据导入导出、更新。 |

---

## 5. AI 配置（可选）

AI 不是必需项。不配置也能拍照、本地 OCR、整理题库和生成「整理错题」练习卷。

1. 到服务商控制台申请 API Key：DeepSeek、智谱 GLM、硅基流动、阿里云百炼、火山方舟等都可以。
2. 打开 **设置 → 模型与 API → 添加 API 配置**。
3. 不想手填地址，就在配置页里点「免费服务商」里的预设；预设只填地址与模型名，不提供共享 Key。
4. 填对话模型；如果希望扫描时用 AI 识图切题，再填视觉模型。**视觉模型留空 = 只走本地 OCR。**
5. 点「测试连接」确认地址与 Key。配置会自动保存，不需要再点保存。

安全与边界：

- API Key 用 Android Keystore 加密保存，不会出现在日志、界面回显或导出包里。
- 换手机需要重新填写 Key（导出包不含 Key）。
- 只有你主动使用 AI 功能时，当前文本或当前附图才会发给你配置的服务商；对方如何处理以其隐私政策为准。
- AI 生成的内容需要自己核对，尤其是题干与答案。

### AI 能做什么

- **题目详情**：AI 讲解（开一个新会话）、AI 整理（回填题干 / 答案 / 解析，可编辑预览）、生成同类题（可全部入库）。
- **AI 对话**：流式回复、思考过程、Markdown 与公式渲染、附图提问、从题库带题。
- **扫描**：视觉模型直接框出题目区域，失败自动回退本地 OCR。

## 6. 生成练习卷

1. 打开「生成」，选择标签；可多选，并切换「全部满足 / 任一满足」。不选标签 = 从全部错题出题。
2. 选出题方式：
   - **整理错题**：抽原题，附解析；
   - **AI 同类题**：换数字再练，失败会自动回退为「整理错题」。
3. 选题量 5 / 10 / 15 / 20，决定是否附答案解析，也可以改练习卷标题。
4. 点「生成练习卷」→ 预览 → 点「打印 / PDF」→ 在系统打印面板里选打印机或「另存为 PDF」。

## 7. 数据与备份

| 操作 | 路径 | 说明 |
| --- | --- | --- |
| 导出 | 设置 → 数据 → 导出题库 | ZIP 含题目、标签、对话、图片；**不含 API Key** |
| 导入 | 设置 → 数据 → 导入题库 | 按「原文 + 创建时间」判重，同一个包导两次不会翻倍 |
| 换机 | 旧机导出 → 新机导入 | 新机需要重新填 API Key |
| 重处理图片 | 设置 → 数据 → 重新处理题目图片 | 统一摆正、白底黑字；**会覆盖现有题目图，建议先导出备份** |

注意：错题只存在本机，系统云备份已关闭。卸载 App 或清除应用数据会删掉本地题库。

## 8. 界面与主题

- **界面风格**：设置 → 外观 → 界面风格，可在澎湃 OS（默认）、iOS、0.9.0 液态玻璃、MD3 Expressive 之间即时切换，不需要重启。
- **主题**：跟随系统 / 浅色 / 深色，与界面风格是两个独立维度。
- **开屏动画**：可在 设置 → 外观 关掉，启动直接进主界面。
- 四套皮肤共用同一套页面和 ViewModel，切换不会重置导航或数据。

## 9. 隐私与权限

Errata 申请的权限：

| 权限 | 用途 |
| --- | --- |
| 相机 `CAMERA` | 拍摄错题；拒绝后仍可手动建题 |
| 网络 `INTERNET` / `ACCESS_NETWORK_STATE` | 调用你配置的 AI 服务、检查更新 |
| 安装应用 `REQUEST_INSTALL_PACKAGES` | 应用内下载新版本后拉起系统安装器 |

不申请存储权限：导出与导入都走系统文件选择器（SAF）。

其他事实：

- 不收集使用数据，不含统计 SDK 与广告。
- 扫描图片、OCR 文本、题目与对话都留在本机。
- API Key 加密存储；导出包不含明文 Key。
- 只有主动使用 AI 时，才把当前内容发给你配置的服务商。

## 10. 常见问题

**没有网络、没有 API Key 能用吗？**
能。拍照、透视矫正、本地 OCR、题库、标签、搜索、统计和「整理错题」练习卷都不依赖网络。AI 对话、AI 整理、AI 同类题和检查更新需要网络与 Key。

**识别不准怎么办？**
先把纸铺平、光线打匀、四角留在画面里；拍完把四个角拖到纸的角上再确认。配置视觉模型后可以让 AI 先切题；入库后还能手动改题干。

**图片会被上传吗？**
不会。扫描与 OCR 都在本机完成。只有你主动使用 AI 时，当前文本（以及对话里你附的图）才会发给你配置的服务商。

**API Key 安全吗？**
Key 用 Android Keystore 加密保存，不会出现在日志、界面回显或导出包里。换手机后需要重新填写。

**怎么备份或换手机？**
旧机：设置 → 数据 → 导出题库，保存 ZIP；新机装好后：设置 → 数据 → 导入题库。导出包不含 API Key，新机要重新配一次。

**卸载后数据还在吗？**
不在。删题、删标签、清空数据和卸载都会影响本地数据；系统云备份已关闭，卸载或清除数据前一定先导出 ZIP。

**AI 收费吗？**
App 本身不收费。额度与价格由你选择的服务商决定；内置预设只填地址和模型名，不提供共享 Key。

**为什么安装包这么大？**
中文 OCR 模型（ML Kit 捆绑版）打进了 APK，换来断网可用与国内无 GMS 环境可用。
