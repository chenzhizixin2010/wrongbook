# v0.10.0

> 0.9.x → 0.10.0 属于大版本更新，打开 App 会看到更新提示。

## 新增

- **输出无限制**：最大输出新增「无限制」选项，不再发送 `max_tokens`，由服务端决定上限
- **练习卷历史**：生成页保存每次生成的卷子（最多 30 份），点开可重新打印或另存 PDF，单条可删
- **纸面提亮（保留彩色）**：用光照归一化把灰纸推到接近纯白，红笔、蓝笔、铅笔痕迹都保留，不再做黑白二值化
- **历史图片重处理**：设置 → 数据 → 重新处理题目图片，把已入库的老图也摆正并提亮
- **摆正支持 180°**：竖着拍反了也能自动转正
- **选项自动换行**：选择题「A. … B. … C. … D. …」挤一行时，生成练习卷会按选项边界断行

## 修复

- **改温度后 API Key 消失**（严重）：保存时用空串覆盖了数据库里的密文，现在会保留原值。之前被抹掉的 Key 需要重新填一次
- **API 编辑页布局错乱**：「最大输出」被塞进了温度那一行，文字和选项挤在一起
- **全面屏侧滑返回页面重叠**：每个页面补上不透明底层，转场时一页盖一页
- **顶部/底部白条**：底图改为全屏出血，与状态栏、手势条融合

- **AI 同类题解析更宽容**：中英文键名（stem/题干、answer/答案）、`items`/`data`/`题目` 等数组名都认；连 JSON 都不是时按题号切段兜底

## 改进

- 返回动画改为 iOS 风格的横向滑页
- 保存按钮独占一行，测试连接 / 测试识图 并排，窄屏不再压字
- 免费服务商选择移到 API 字段（模型、温度）下方，先配好再选预设更顺手
