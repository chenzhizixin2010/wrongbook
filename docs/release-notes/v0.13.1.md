# v0.13.1

> 0.13.0 的紧急修复版，**强烈建议升级**：0.13.0 上「点开题目详情」和「打开 AI 对话」会闪退。
> 只有修订号变化，不会弹「建议更新」，请在 **设置 → 检查更新** 里手动更新。

## 修复

- **点开题目就闪退**（严重）：只要题目的题干是「AI 整理」过的文本，进入详情页就会崩溃；
  AI 对话里收到带公式的回复也会崩。
  原因是 Markdown 渲染链里打开了「行内公式」开关，但没装它依赖的 `inline-parser` 插件，
  Markwon 在装配阶段直接抛空指针。已补上插件，并给渲染器加了兜底——万一以后再装配失败，
  会退化成纯文本显示，不会再让整页崩掉。
- **行内公式仍然显示不出来**：`$x^2$` 这种单美元公式，Markwon 的 LaTeX 插件其实只认 `$$...$$`
  （它的正则就是 `(\${2})([\s\S]+?)\1`），单美元永远当普通字符。现在渲染前会把单 `$...$`
  升级成 `$$...$$`（已经是双美元的不动，`$5 和 $10` 这种价格写法也不会误伤）。
- **超分自检提示「模型能加载但推理没结果」**：自检用了一张 128×128 的图，但分块步长是 112
  （128 减去两侧 8px 重叠），所以这张图实际要切成 2×2=4 块，而自检只给了 1 块的预算，
  于是被判成「太大、跳过」。现在自检按真实预算跑，并直接报「几块、总耗时、平均每块」。
- **「重新处理题目图片」可能把主图覆盖成缩略图**：旧逻辑用 `path.replace(".webp", "_thumb.webp")`
  推缩略图路径，遇到非 `.webp` 的老图片（`.jpg` / `.png`）会得到和主图相同的路径，
  于是拿 200px 的缩略图把主图覆盖了。现在按扩展名正确推导，推导结果与主图同名就跳过重建。
- 重处理图片的替换步骤不会再「先删后改名」：改名失败直接覆盖写，并把「新图能不能解出来」
  作为覆盖的前置条件——宁可这张不处理，也不能让数据库指向一个不存在的文件。

## 调整

- 超分耗时文案按实测放宽为「约 5–15 秒（看机型）」，具体以 设置 → 图像增强 → 超分自检 为准

## 说明

- 这几处都是纯客户端逻辑，不涉及数据库迁移，不影响已有题目与图片（被 0.13.0 覆盖成缩略图的
  图片无法自动恢复，只能重新上传那张插图）
- 新增 18 条单元测试：公式分隔符归一（12）、缩略图路径推导（6）
