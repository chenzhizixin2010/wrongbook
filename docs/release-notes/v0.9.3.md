# v0.9.3

## 改动

### 输出不再动不动被截断

- 新配置默认输出上限 2048 → **8192**；配置页可选 4096 / 8192 / 16384 / **32768**
- 出题、识图、补答案这些调用**跟随你的设置**，不再写死 4000
- 真被截断时（`finish_reason=length`）App 会**自动续写一次**，把后半段接到同一条消息；手动停止则不续写

### 题库 ↔ AI 对话 双向打通

- **题库 → 对话**：题目详情点「AI 讲解」，自动新建会话并带入**整理后的题干**（以前带的是 OCR 原文，错字多）
- **对话 → 题库**：每条回复下「存为错题」，自动拆题干 / 答案 / 解析，可改、可选标签
- **对话 → 题库（引用）**：对话页右上「选题」，搜索题库后把题干插进输入框继续问

### AI 出题

- 选「AI 同类题」但没检测到可用 API 时，生成页直接红字提示（多半是 Key 没保存）
- 出题失败不再静默回退：会说明是「没有 Key / 超时 / 无法解析」哪一种
- JSON 模式失败自动换普通模式重试

### 缺少答案与解析

- 生成练习卷前先检查：有缺口会问你「要用 AI 补全吗？」
- 补全结果**写回题库**，下次不用再补；也可以选「跳过」按现状出卷

## 说明

- 0.9.2 → 0.9.3 只有修订号变化，不会弹窗，可在「设置 → 检查更新」查看
- 如果「测试识图」提示读不到 Key，说明 Key 没保存成功，重新贴一次并点保存
