# v0.9.1

## 修复

- **透视矫正四角拖不动**：手势输入被自己的状态更新打断（拖动时每帧重启），现在可以正常拖动；命中半径从 44dp 放大到 56dp
- **AI 识图静默失败**：整页题目超出 token 上限会被截断，之前只是悄悄降级成本地识别。现在上限放大到 4000，失败会自动关掉 JSON 模式重试一次，仍然失败会在界面上写明原因
- **本地 OCR 提升**：识别前做灰度 + 对比度增强并补足分辨率；过滤只有一两个字符的碎片行，减少错切
- **AI 识图提示词**：明确要求忽略手写答案、批改、圈画、打勾打叉，只转录印刷体

## 新增

- 题目文字可以**手动编辑**（题目详情页 → 题干右上角「编辑」），识别不准也有兜底

## 说明

- 0.9.0 → 0.9.1 只有修订号变化，属于小版本，**不会弹窗**，可在「设置 → 检查更新」查看
- 如果扫描后仍显示本地识别，界面会给出具体原因（超时 / 限流 / Key 无效 / 解析失败），按提示排查即可
