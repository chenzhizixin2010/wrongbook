# v0.9.0（测试版）

> 这是 1.0 正式版之前的测试版，用来验证新界面、免费服务商接入和更新流程。
> 试用中发现问题请直接反馈，正式版会按反馈修完再发。

## 新增

- **全新视觉**：液态玻璃界面、极光背景、悬浮标签栏；深色 / 浅色 / 跟随系统
- **品牌与开屏**：应用更名 Errata（AI 错题本），新增品牌标记、启动页与全新图标（含深色版）
- **10 家免费服务商预设**：火山方舟·豆包、智谱 GLM、美团 LongCat、阿里云百炼、硅基流动、魔搭、DeepSeek、Groq、OpenRouter、Gemini
  - 每项点开都有「去哪申请 Key」直达链接和领取步骤，可一键填入地址与模型名
- **更新日志进弹窗**：Release 正文会作为更新说明显示，自动清理 Markdown 符号；大版本提示、小版本静默
- 下载更新时显示百分比、实时速度、已下载/总大小、剩余时间与下载源
- 「生成」页：按标签出练习卷，支持整理错题 / AI 生成同类题，可打印或另存 PDF
- 学习统计、标签现场新建、对话会话删除

## 修复

- 透视矫正手柄过小（改为 dp 绘制 + 44dp 命中半径）
- 按钮文字对比度（灰字压蓝底）
- 清单缺少 INTERNET 权限，AI 请求在真机失败

## 说明

- 0.4.0 → 0.9.0 属于大版本更新，打开 App 会看到更新提示
- 免费额度以各家官网为准，政策变动代码不做硬判断
