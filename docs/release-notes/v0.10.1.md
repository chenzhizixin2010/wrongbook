# v0.10.1

## 修复

- **应用内更新点「下载」直接崩溃**：探测镜像速度时用了 `InputStream.readNBytes()`，这个方法只有 Android 13（API 33）才有，而应用最低支持 Android 7（minSdk 24），所以点下载就抛 `NoSuchMethodError`。已换成手写读取循环。
- 测速阶段会显示「正在测速选择最快的源…」，不再让界面看起来像卡住。

## 注意

- 如果你现在还停在 0.10.0，**应用内更新是坏的**，需要手动装一次这个 APK；从 0.10.1 起自动更新恢复正常。
- 0.10.0 → 0.10.1 只有修订号变化，不会弹窗，可在「设置 → 检查更新」查看。
