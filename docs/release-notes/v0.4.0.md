# v0.4.0

## 新增

- **「生成」页**（替换原「巩固」）：选标签 → 整理错题 / AI 生成同类题 → 可打印或另存 PDF
- **学习统计**独立成页（设置 → 学习统计）：掌握度分布、标签分布
- **免费服务商预设**：智谱、硅基流动、魔搭、Groq、OpenRouter、Gemini，点开有申请直达链接和步骤
- **主题切换**：深色 / 浅色 / 跟随系统
- **更新提示分级**：大版本弹「建议更新」，小版本不打扰；下载显示进度、速度、剩余时间
- 对话会话可删除；标签可在扫描/建题时现场新建，数量不限

## 修复

- 透视矫正手柄按 dp 绘制（原来 18px，高密度屏上几乎点不中）
- 按钮文字对比度（灰字压蓝底看不清）
- 清单缺少 INTERNET 权限，导致 AI 请求在真机失败

## 移除

- 复习调度、每日提醒、通知权限（改为「生成」练习卷）
