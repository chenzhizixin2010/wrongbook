# v0.12.0

> 0.11.0 → 0.12.0 属于大版本更新。注意：从这个版本起，所有 0.x 版本在 GitHub 上都标记为 pre-release，需要在「设置 → 关于 → Beta 计划」里开启才会收到更新提示。

## 新增

- **开屏动画开关**：设置 → 外观，关掉后启动直接进主界面
- **API 配置自动保存**：不再需要点「保存」，任何字段改完 700ms 自动落库，页面底部显示保存状态
- **关于开发者**：版本信息、GitHub 仓库与 Issues、技术栈与开源许可、隐私说明
- **Beta 计划开关**：开启后接收 GitHub 上的预发布版本，测试版更新一律弹窗；关闭则只查正式版

## 调整

- **输出上限默认「无限制」**：不再发送 `max_tokens`，由服务端决定
- 输出档位整体放大 50 倍：204800 / 409600 / 819200 / 1638400（大多模型会自行截断，一般选「无限制」即可）

## 说明

- GitHub 上 11 个历史版本已全部标记为 pre-release；CI 对 `v0.*` 自动打该标记，1.0 之后取消
- 未开启 Beta 的用户在当前阶段查不到更新，会看到「开启 Beta 计划后可获取」的提示
- 老配置里已保存的 token 数值不会自动变化，进配置页重选一次即可（会自动保存）
