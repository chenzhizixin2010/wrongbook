# v0.9.4

## 新增

- **历史练习卷**：生成页会保存每次生成的卷子（最多 30 份），点开可重新打印或另存 PDF，单条可删
- **题目图片白底黑字**：入库前用 Sauvola 局部二值化处理，阴影和手影下笔画也不会丢；二值化失败会自动退回灰度增强
- **自动摆正支持 180°**：竖着拍反了、横着拍竖版，都会先试 0°/90°/180°/270° 再转正

## 修复

- **全面屏侧滑返回时页面重叠**：每个页面新增不透明底层（纯色 + 静态极光），转场时一页盖一页，不再互相透视
- 去掉系统导航栏压暗层，底部不再多一条灰边

## 说明

- 0.9.3 → 0.9.4 只有修订号变化，不会弹窗，可在「设置 → 检查更新」查看
- 白底黑字只对**之后新扫描**的题目生效；已入库的旧图不会自动重做
