# v0.11.0

> 0.10.1 → 0.11.0 属于大版本更新，打开 App 会看到更新提示。

## 新增

- **三套皮肤**：默认 Miuix（HyperOS 风格，跟随系统取色）、iOS（Cupertino）、液态玻璃（0.9.0 复古），设置里可切换，页面逻辑与数据完全共用
- **数学公式显示**：题目详情用 Markdown + LaTeX 离线渲染（`$x^2$`、`$$\int$$` 都能排版）；练习卷打印走轻量公式转换（上标下标、×÷≤≥π 等）；导出的 Word 保留纯文本公式
- **导出 Word**：练习卷预览页可直接另存为 `.docx`（标题、题目、答案分页排版）
- **历史练习卷**支持导出 Word（0.10.1 之前生成的旧卷没有结构化数据，会提示重新生成）

## 修复

- **历史错题图片不摆正**：OCR 读不出字时方向判断全部归零，现在补了投影轮廓兜底（横排/竖排按墨迹分布判断），低清老图也能转正
- **更新日志弹窗透明**：改为不透明底色，底下页面文字不再透上来
- **检查更新的链接点不动**：直链现在可点击，另加「打开下载页」按钮
- **主界面切换动画**：五个 Tab 恢复淡入淡出，只有进/出二级页面才用滑页

## 说明

- 转正 + 提亮历史图片：设置 → 数据 → 重新处理题目图片
- 0.10.0 之前版本的应用内更新因 `readNBytes` 兼容问题会崩，已在 0.10.1 修复
