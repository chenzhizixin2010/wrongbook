# v0.9.2

## 新增

- **已入库的题可以改标签**：题目详情 → 标签 → 「编辑」，点选立即生效，也能现场新建标签
- **AI 对话里的题可以直接入库**：每条回复下方「存为错题」，自动拆出题干 / 答案 / 解析（都能改），选完标签一键保存
- **配置页「测试识图」**：用设备现画的样张跑一遍真实视觉链路，成功显示识别到几道题，失败直接给原因（Key 无效 / 404 / 超时 / 解析失败）
- **题库批量删除**：右上「选择」→ 勾选 → 删除（N），带二次确认
- **拍照自动框选有文字的区域**：透视页初始框不再固定内缩，而是先扫描墨迹外接框
- **自动摆正横竖**：横着拍竖版试卷时，先试 0°/90°/270° 取识别字符最多的方向再转正

## 修复

- **AI 对话被截断**：默认输出上限 2048 → 4096（老配置也强制抬到 4096），配置页可调到 8192 / 16384；对话页顶部新增「继续」，已截断的回答可以让模型接着写
- **更新下载太慢**：下载前并行测速，自动选最快的源；镜像清单换成本次实测可用的（gh-proxy.org / gh-proxy.com / gh.monlor.com / ghproxy.net / ghfast.top）

## 说明

- 0.9.1 → 0.9.2 只有修订号变化，不会弹窗，可在「设置 → 检查更新」手动查看
- 识图自检如果提示「读不到 Key」，说明 Key 没保存成功 —— 重新贴一次并点保存
