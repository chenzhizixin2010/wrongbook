## 新增

### 版本计划：正式版 / Beta / Alpha

- **设置 → 关于 → 测试版计划**：点开是三档单选弹窗，**默认 Beta**
  - **正式版**：只收 GitHub 上非 pre-release 的稳定版本
  - **Beta**：收正式版 + Beta 测试版，有新测试版一律弹窗
  - **Alpha**：收最新内测版（`0.13.A01` 这种），功能最新、可能不稳定
- Alpha 版本号形如 `0.13.A01`，同一大版本内按 `A01 → A02` 递增；正式版永远比同号 Alpha 新，所以从内测升正式能正常收到提示
- Alpha 的安装包放在独立的**分发仓库**（只有 Release、没有源码），主仓库只留正式版与 Beta，版本列表不再混在一起
- 更新弹窗会明确告诉你收到的版本来自哪条通道（Alpha 内测 / Beta 测试版 / 正式版）

### AI 出题质量

- **四段式出题**：先让模型分析考点出「出题蓝图」，再按规范出题，然后本地质检，不合格的题带着原因返工重出
- **离线题型风格库**：按学科（数学/物理/化学/生物/英语/语文/历史/地理/政治）内置真实考卷的设问方式与干扰项套路，模型照着写，不用联网
- **联网搜题开关**：生成 → 出题方式 → 联网搜题（默认开）。模型支持服务端检索时会先查真实题目；不支持的模型会自动回退到本地题型库，并在提示里说明
- **质量闸门**：以下题目不会印到卷子上，而是打回重出——
  - 依赖插图的题（「如图所示」但 AI 生成不了图）
  - 答案写「略 / 见解析」、或答案不在选项里的选择题
  - 缺解析、解析太短
  - 跟原题几乎一样，或本次两道题重复
  - 只改了措辞、数字没变
- 被刷掉多少道、为什么刷掉，生成完会弹「出题提示」告诉你，不再默默少题

### 答案拍照录入

- 「答案与解析 → 扫答案」现在**直接开相机**：对准答案页按快门，OCR 识别后弹校对框，改完保存
- 里外都有兜底：没给相机权限会提示并给「从相册选」；相机不可用也能走相册
- 拍照后先自动摆正（0°/90°/180°/270° 四个方向试 OCR，取识别字最多的方向），横着拍/拍反了都能认

### 插图超分（EDSR ×4）

- 内置 **EDSR ×4** 超分模型（7.4MB，Apache-2.0），题目插图「高清重绘」现在是真 AI 超分：小图放大 4 倍，文字和线条边缘明显更利
- **刻意没用生成式（Real-ESRGAN 这类）**：GAN 会「脑补」笔画，数学图形和公式被改一笔就变成错题；EDSR 只拉清楚已有边缘，不凭空造细节
- 分块推理：每块 128×128 带 8px 重叠，算完裁掉重叠区，避免拼缝；一次最多 9 块（约 5–8 秒），超过就自动退回 Lanczos，不会让人以为卡死
- 设置 → 图像增强：可以关掉超分（秒出），也可以点「超分自检」在这台手机上真跑一次，直接看到耗时或失败原因
- 效果对比（左双三次、右 EDSR ×4，输入是模拟拍糊的小图）：仓库里 `docs/sr-compare.png`

### 题目插图与备份

- 题目详情可加多张插图，插图会一起进练习卷（打印/PDF/Word 都带图），也会一起进备份 ZIP，换机不丢
- 备份格式升级，老备份仍可导入（没有插图字段按空处理）

### OCR 推荐标签

- 扫描页识别完会根据 OCR 文本给出建议标签（离线规则：学科 + 知识点两张表），一键套用，也可以当场新建

- 第一次打开 App，开屏结束后显示 5 页快速介绍（核心理念、扫描入库、标签分类、AI 可选、数据与隐私），可跳过；看完或跳过只显示一次

- 手册顶部可重看 5 页快速引导；题库空状态里多一个「查看使用手册」按钮

## 调整

- 「Beta 计划」开关改成「测试版计划」弹窗，三档单选更直观
- 检查更新页会显示当前所在通道
- 插图「高清重绘」默认走 AI 超分，慢一点但更清楚；可在设置里关掉改回秒出的 Lanczos
- AI 出题提示词里明确要求「难度与原题一致、不超纲」
- 首次启动仍不检查更新，避免「建议更新」弹窗压在引导上

## 修复

- **AI 讲解里的行内公式不显示**：`$-110.5\mathrm{kJ/mol}$` 这类行内公式被当成普通文字。原因是 LaTeX 插件默认只渲染块级公式，现已打开行内渲染，并兼容 `\(...\)`、`\[...\]`、双重转义 `\\mathrm` 和被反引号包住的公式
- 题干自带「1.」「题目 1：」时，练习卷会出现重复编号，现在会自动剥掉
- 选项挤在一行（`A. 1 B. 2 C. 3 D. 4`）会被从选项中间折断，现在按选项边界换行
- AI 生成的选择题如果是残缺选项或答案对不上，不会再印到卷子上一错到底

## 说明

- 版本计划存在本地 DataStore，不涉及数据库迁移，不影响已有题目
- 老用户升级后默认就是 Beta，行为与原来一致（原来的 Beta 开关等同于现在的 Beta 档）
- 联网搜题只在第一轮出题时尝试，避免每轮都多等一次；不支持的服务端会被静默降级并在提示里写明
- **安装包变大了**（约 66MB → 72MB）：多了 7.4MB 模型 + TensorFlow Lite 运行时。为控制体积已去掉 32 位 x86（没有在售设备了），保留 arm64 / armv7 / x86_64
- 超分只对**小图**（长边 ≤ 336px，即 9 块以内）生效；大图本来就不缺像素，继续用 Lanczos + 反锐化
- 插图超分是纯本地推理，不联网、不上传任何图片
