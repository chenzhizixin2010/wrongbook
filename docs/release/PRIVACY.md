## 一、我们收集什么

本应用是**纯本地**的错题本工具。默认情况下：

| 数据类型 | 是否收集 | 存放位置 |
| --- | --- | --- |
| 你拍摄/选择的题目图片 | 是 | 仅存在本机 App 私有目录 |
| OCR 识别出的文字 | 是 | 仅存在本机数据库 |
| 标签、掌握度、复习记录 | 是 | 仅存在本机数据库 |
| AI 对话内容 | 是 | 仅存在本机数据库 |
| 大模型 API Key | 是（加密） | 仅存在本机 Keystore，加密后落库 |
| 位置、通讯录、设备标识 | **否** | — |
| 崩溃日志、埋点统计 | **暂未接入** | — |

## 二、什么时候会联网

只有一种情况：**你主动配置了大模型 API 并发起请求**（AI 对话、AI 整理、生成同类题、测试连接）。

此时会发送给对应服务商（如 DeepSeek）：

- 你输入的文本；
- 若你选择了「AI 讲解某道题」，会发送该题的识别文字（**不会**发送整本图库，也不会后台上传）；
- 对话历史（为让模型理解上下文）。

服务商如何处理这些数据，适用其自身隐私政策。你可以在「设置」里随时删除配置，删除后不再有任何联网请求。

## 三、我们不会做的事

- 不会在后台自动上传图片或题目；
- 不会把 API Key 写进日志、备份包或崩溃报告；
- 不会把数据卖给第三方；
- 不会申请通讯录、位置、短信等与本功能无关的权限。

## 四、权限说明

| 权限 | 用途 | 能否拒绝 |
| --- | --- | --- |
| `CAMERA` | 拍摄题目 | 可以。拒绝后仍可用「导入题库」或手动录入 |
| `POST_NOTIFICATIONS` | 每日复习提醒 | 可以。拒绝后只是收不到提醒 |

导出/导入使用系统文件选择器（SAF），**不申请**任何存储读写权限。

## 五、数据的保存与删除

- 数据保存在本机，卸载 App 即全部删除；
- App 内可逐条删除题目、会话、标签；
- 「设置 → 数据 → 导出题库」可生成 ZIP 备份自行保存；
- 我们没有服务器，因此**无法**帮你远程恢复已删除的数据。

## 六、未成年人

本应用不面向 14 周岁以下儿童单独提供服务。若你是未成年人，请在监护人同意后使用。

## 七、政策更新

政策变更时，我们会在 App 内提示，并更新本页面的「生效日期」。
