# 上架前检查表

> 每一项都标了「谁能做」：🤖 = 智能体能做，👤 = 必须你来定。
> 打勾前请真机验证，不要只看代码。

## 一、功能验收（👤 真机）

- [ ] 飞行模式下：拍照 → 调整边框 → 识别 → 选 3 题入库 → 题库可见 → 详情可看（本地 OCR 必须完全可用）
- [ ] 一题打 3 个标签；用两个标签 AND 筛选能命中；删标签后题目还在
- [ ] 配置真实 API Key → 测试连接成功 → 新建对话 → 流式回复正常、公式能渲染
- [ ] 题目详情「AI 整理」能回填题干/答案/解析；「同类题」能生成并入题库
- [ ] 导出 ZIP → 清空数据（卸载重装）→ 导入 → 题目与图片完整还原
- [ ] 复习：答对后间隔变长、答错 10 分钟后重新出现
- [ ] 通知：授权后到点能收到提醒；拒绝授权也不崩溃
- [ ] 深色模式、小屏机型、系统字体放大后布局不炸
