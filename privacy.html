PRIVACY

隐私政策

适用于 Android 应用 Errata（包名 com.chenzixin.wrongbook）及本网站
运营者：chenzhizixin2010（个人开发者）
生效日期：2026 年 11 月 28 日 · 最后更新：2026 年 11 月 28 日

一句话版本：Errata 没有服务器，也没有账号。题目、图片、标签、对话默认只保存在你的手机里；只有你主动配置并调用大模型时，必要的文本或图片才会发送给你选择的服务商。

本政策说明 Errata 会处理哪些信息、为什么处理、存放在哪里，以及你可以如何删除它们。我们尽量用直白的语言写，不用模糊的「可能」「相关」来掩盖事实。

一、我们处理哪些信息

信息类型何时产生存放位置是否会离开设备
题目图片、插图 拍照、从相册选择或手动添加 本机 App 私有目录 默认不会。只有你主动使用 AI 识图，或给对话附图时，当前这张图片才会发给你配置的服务商
OCR 原文、题干、答案、解析 本地 OCR、AI 整理或手动输入 本机 Room 数据库 默认不会。只有你主动发起 AI 讲解、整理、生成同类题时，必要文本才会发送
标签、掌握度、复习记录 使用过程中 本机 Room 数据库 不会
AI 对话 你主动发起对话 本机 Room 数据库 对话内容与上下文会发送给你选择的服务商
大模型 API Key 你在设置里添加配置 本机，Keystore AES/GCM 加密后落库 只用于向你配置的服务商发起请求；不会出现在日志、崩溃信息或导出包里
位置、通讯录、短信、设备广告标识 — 不收集 不适用
崩溃日志、行为埋点、统计 SDK — 暂未接入 不适用

如果你在 App 内删除题目、标签或会话，对应的本地记录会被删除；卸载 App 会清除应用私有目录中的全部数据。

二、什么时候会联网

只有下面几种情况。除此之外，Errata 不会主动联网。

1. 你主动使用 AI 功能

当你在设置里配置了大模型 API，并发起 AI 对话、AI 讲解、AI 整理、生成同类题或测试连接时，App 会把完成这次请求所必需的文本发送给你选择的服务商，例如：

  • 你输入的提问文本；
  • 你选择「讲解这道题」时，该题的题干与解析文本；
  • 为让模型理解上下文而附带的历史对话；
  • 你主动附上的图片（只发送当前这条，不会上传整个图库）。

我们不会在后台自动上传题目或图片，也不会把整本错题本同步到任何服务器。服务商如何处理这些数据，适用其自身的隐私政策；你可以在设置里随时删除配置，删除后不再有对应请求。

2. 检查更新与下载安装包

检查更新时，App 会向 GitHub Releases 发起请求，读取版本号与更新说明；下载 APK 时也会连接 GitHub。GitHub 会按自己的规则记录常规请求信息（如 IP 地址、User-Agent），适用 GitHub 的隐私声明。

3. 访问本网站

本站由 GitHub Pages 托管。打开本站时，GitHub 可能记录常规访问日志，适用 GitHub 的隐私声明。本站不接入统计、广告或第三方字体服务。

Errata 没有自己的服务器，也没有账号体系，因此不存在「Errata 云端数据库」。

三、权限说明

权限用途拒绝后会怎样
CAMERA 拍摄试卷、题目 仍可手动新建题目、从相册选图或导入备份
INTERNET 调用你配置的大模型、检查更新、下载安装包 离线功能仍可用：拍照、本地 OCR、题库、标签、生成原题练习卷
ACCESS_NETWORK_STATE 判断当前网络状态，失败时给出提示并降级 不影响本地功能，但网络失败提示可能不够准确
REQUEST_INSTALL_PACKAGES App 内下载新版本后调起系统安装器 仍可手动前往 GitHub Releases 下载安装

导出和导入使用 Android 系统文件选择器（SAF），不申请存储读写权限；不申请位置、通讯录、短信或通知权限。

四、数据保存、备份与删除

  • 数据保存在本机 App 私有目录与 Room 数据库中，受 Android 应用沙箱保护。
  • 你可以在 App 内逐条删除题目、标签、会话，或清空数据。
  • 「设置 → 数据 → 导出题库」会生成一个 ZIP，包含题目 JSON、标签、对话和图片，不包含 API Key。ZIP 保存到你选择的位置，之后由你自行保管。
  • 导入备份时，App 会按「原文 + 创建时间」判重，自动跳过重复题；导入过程不经过任何服务器。
  • 卸载 App 会删除本机数据。我们没有服务器，因此无法帮你远程恢复已删除的数据。

五、安全措施

  • API Key 使用 Android Keystore 的 AES/GCM 加密后保存，不以明文落库。
  • API Key 不会出现在日志、异常信息、崩溃报告或导出包中。
  • 内置服务商预设与 GitHub 通信使用 HTTPS；如果你自行填写 HTTP 地址，该段链路的安全由你和对应服务负责。
  • 题目图片保存在 App 私有目录，其他应用无法直接读取。

没有任何系统能保证 100% 安全。请为手机设置锁屏密码，并定期导出备份；不要把包含个人题目的 ZIP 随意分享给不可信的第三方。

六、未成年人

Errata 不面向 14 周岁以下儿童单独提供服务。若你是未成年人，请在监护人同意和指导下使用；监护人如发现相关数据需要删除，可直接在 App 内删除或卸载应用。

七、政策更新与联系方式

如果本政策发生实质性变化，我们会更新本页面的「最后更新」日期；如有必要，也会在 App 内提示。继续使用即表示你接受更新后的政策。

对本政策有疑问，或希望行使删除、导出等权利，请通过 GitHub Issues 联系：
github.com/chenzhizixin2010/wrongbook/issues
